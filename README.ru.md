# MedSpravki REU

**[English version →](README.md)**

Студенческий веб-реестр по реальному ТЗ кафедры физвоспитания РЭУ им. Плеханова: учёт медицинских справок и допусков студентов к занятиям. Проект завершён и передан заказчику — кафедре.

![Реестр медицинских справок с синтетическими демо-студентами](assets/readme/registry.png)

**Стек:** .NET 8 · C# 12 · ASP.NET Core Razor Pages · Entity Framework Core 8 · PostgreSQL 16 · локальная vision-модель в Ollama · xUnit

История разработки и датированные проверки хранятся в [docs/PROJECT-STATUS.md](docs/PROJECT-STATUS.md).

## Что умеет

- Искать и фильтровать студентов по подразделению, курсу, группе и преподавателю.
- Хранить срок справки, группу здоровья, физкультурную группу, ограничения и статус проверки.
- Собирать список «Перед парой», где сверху видны студенты без действующей справки.
- Принимать PDF и изображения и направлять заявки на проверку сотруднику.
- Локально читать скан через Ollama и предлагать значения полей; результат подтверждает человек.
- Вести историю справок и журнал действий; разделять доступ студента, преподавателя, заведующего и администратора.

## Как это работает

```text
PDF или фото → локальная vision-модель Ollama → черновик полей → проверка сотрудником → запись в PostgreSQL
```

Загруженные файлы лежат вне публичной папки сайта. Распознавание создаёт черновик, а не принимает решение. Провайдер `Manual` позволяет работать с реестром без Ollama и GPU.

## Запуск

Нужны .NET 8 SDK, Docker и свободный локальный порт `5432`.

```bash
git clone https://github.com/Archangel-gabri/medspravki-reu.git
cd medspravki-reu/app

docker run --name reu-pg -d \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=reu_med_certificates \
  -p 5432:5432 postgres:16

ASPNETCORE_ENVIRONMENT=Development \
BootstrapUser__Enabled=false \
SeedDemoData=true \
DEMO_USER_PASSWORD='choose-a-local-demo-password' \
Recognition__Provider=Manual \
dotnet run --project src/ReuMedCertificates.Web --urls http://localhost:5080
```

Откройте `http://localhost:5080` и войдите под логином `teacher` с паролем из `DEMO_USER_PASSWORD`. Студенты и справки в демо-сиде полностью синтетические.

## Ограничения

- Официальное ТЗ v1 описывает ручной реестр. Загрузка студентом, хранение сканов и распознавание относятся к расширенному объёму студенческого проекта, а не к подтверждённым требованиям заказчика.
- Модель ошибается в рукописных полях и не может доказать подлинность справки. Проверка человеком обязательна.
- Есть юнит-тесты домена и application-слоя, но нет интеграционных и E2E-тестов, а также CI.
- Текущая страница импорта читает SQL или 1С OData. Импорт и экспорт Excel из ТЗ v1 не реализованы.
- На скриншотах только синтетические демо-записи. Для работы с реальными медданными нужен контур под управлением вуза и отдельная проверка защиты данных.
