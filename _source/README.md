# Исходные материалы заказчика

Здесь лежит то, из чего вырос проект. Это **не часть приложения** — код целиком в `../app/`.
Материалы оставлены в репозитории, потому что по ним видно, откуда взялись требования:
студенческий проект делался по ТЗ реального заказчика, а не по выдуманному.

| Что | Где |
|---|---|
| Официальное ТЗ кафедры физической культуры (v1) | `inputs/01_Официальное_ТЗ_МедСправки_РЭУ.md` |
| Подробное техническое ТЗ и архитектура | `inputs/02_Подробное_техническое_ТЗ_и_архитектура_МедСправки_РЭУ.md` |
| Исходный документ заказчика | `inputs/АС мед справки РЭУ.docx` |
| Фотографии рукописных макетов интерфейса | `mockups/` |
| Образец справки формы 086/у | `sample-certs/` |

**Справка в `sample-certs/` нарисованная, не настоящая.** Она нужна как эталон формы для
проверки распознавания; реальных медицинских документов в репозитории нет и быть не может —
это спецкатегория персональных данных (ст. 10 152-ФЗ).

ТЗ обезличены: имён, контактов и фамилий студентов в них нет.
